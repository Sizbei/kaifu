**What moved each metric**

- **カジュアル plain form 7/10 → 10/10.** Japanese-language style sheet with forbidden forms named (です／ます／ください／お願いします), three plain-form exemplars, a 丁寧→カジュアル contrast pair, an explicit rule that reports and plans stay plain (欠席させます→欠席させる), and a one-line register reminder as the last line of the user prompt. No retry loop was needed.
- **最敬語 with 尊敬語 8/10 → 10/10, 敬語→最敬語 similarity 0.54 → 0.44, LENGTH_INVERSION 4–8 → 0–1.** The 最敬語 spec now demands a re-cast body (word-substitution table: 教えて→ご教示賜りたく, 分からない→把握いたしかねる …), mandatory 賜る／何卒／〜申し上げます, a 拝啓→さて→つきましては→末文→敬具 skeleton, and 6–9 sentences; 敬語 is forbidden 賜る／幸甚／ご高配／時下 so the two rungs cannot converge.
- **NEAR_IDENTICAL 1 → 0** follows from the above plus the 丁寧 spec forbidding 謙譲語 verbs (おります／いたします／申し上げます／伺う／拝見).
- **Misdirected honorifics.** An explicit ✗/○ list (ご参加する, お子さん for one's own child, 弊子ども, 〜と伺っております for one's own situation, ご存じなくて, アレルギーをお持ちで, ご来院いただけなくなりました, 二重敬語, 賜る on one's own payment, thanking for a 督促状) is shown to every rung above カジュアル.

**What a manual read of the final runs still shows** (the automatic checks cannot see these)

- 「お子さん」 for the writer's own child survived once per run, always in the short neighbour-noise 丁寧 draft; the same draft once echoed the instruction 「関係を壊さないように思っています」.
- 「分割納付を…賜りたく」 (賜る on the writer's own payment) appeared once in 最敬語 payment-extension despite being a listed negative example.
- Every deposit-dispute draft names the 国土交通省ガイドライン as leverage. The intent itself asserts it; the strengthened LEGAL BOUNDARY text did not override that. This needs a pre-check on the intent, not more prompt text.
- 最敬語 closes with the same formula (ご多忙のところ誠に恐縮ではございますが、何卒ご高配のほど…) in nearly every letter, and the ward-tax カジュアル／最敬語 drafts are near-verbatim copies of the matching exemplar (same intent by design; the facts happen to coincide). Exemplar facts should be moved further from the eval scenarios before this number is trusted.
- One カジュアル draft (bank-resubmission) came wrapped in 「」; the client's stripper does not remove it.

**Verdict:** the slider is demo-ready on separation — every rung reads as a different rung, and the 敬語/最敬語 bodies now differ — but not yet ship-ready on correctness: a native reviewer should still mark the drafts, and the intent-level legal pre-check is the next engineering move.

## For the native reviewer

You do not need to read the code or the scores. For each of the four drafts in every scenario, fill the **Verdict** column with one mark and add a short note if it is not ✓:

| Mark | Meaning |
|---|---|
| ✓ | Natural. A native speaker could send this to this recipient as-is. |
| △ | Stilted or awkward, but the politeness level is right. Say what you would change. |
| ✗ | Wrong register — too casual, too stiff, or the honorifics are misapplied (e.g. 尊敬語 used about oneself). |

### What the automatic checks cannot catch

The scores below count honorific *markers*. They cannot tell whether a marker points at the right person, which is where keigo actually goes wrong and where your eye is the only instrument. Please watch specifically for:

| Error class | What it looks like |
|---|---|
| 尊敬語 aimed at the writer | ご参加する / ご存じなくて困っております — elevating one's own action or knowledge |
| 謙譲語 aimed at the recipient | 相手に対して「伺う」「拝見する」を使う |
| Honorifics on one's own family | お子さん / ご主人 used for the writer's own child or spouse |
| 二重敬語 | おっしゃられる / ご覧になられる — stacked honorifics |
| Wrong-person hearsay | 〜と伺っております used for the writer's own circumstances |
| Envelope-only formality | 最敬語 that is the 敬語 body with 拝啓/敬具 bolted on, unchanged inside |

The two questions that matter most: **(a)** would you send this to *this specific recipient*, and **(b)** is each step up the ladder a real step — does 敬語 actually read as more deferential than 丁寧, or do they feel the same? The automatic scores below are a first pass only; they cannot judge naturalness.

## How the automatic checks work

- **です・ます率** — only *sentence-final* predicates are classified. Japanese uses plain forms mid-sentence (relative and subordinate clauses) even in the most formal writing, so a mid-sentence 〜する carries no register information and is deliberately ignored.
- **尊敬語** — いらっしゃる / おっしゃる / ご覧になる / なさる / 召し上がる / くださる / お〜になる / ご〜くださる / ご〜いただく / 賜る / 貴社.
- **謙譲語** — いたす / 申し上げる / 伺う / 拝見 / 存じる / 承る / 頂戴 / させていただく / おります / 参る / お〜いたす / 弊社.
- **美化語** — お・ご・御 immediately followed by a kanji, normalised per 100 characters.
- **書簡枠** — hard letter-form markers only (拝啓 / 敬具 / 謹啓 / 謹白 / 前略 / 草々 / 時下 / 〜の候 / ご清栄). These are legitimate **only** in 最敬語; anywhere below that they are an error. Softer markers (何卒 / 平素より / 申し上げます) feed the formality index but are not flagged, because they are normal business 敬語.
- **Formality index (0–100)** — です・ます率 ×25 + 尊敬語 ×12 + 謙譲語 ×23 + 美化語密度 ×12 + 改まり表現 ×8 + 書簡枠 ×20, each capped. It is a separation metric, not a quality metric: a high score means the rendering is *marked* as formal, not that it is correct or natural. Only the native reviewer can judge that.
